# Daily-Fantasy-Game
## Об игре
>Мы играем за Евгения Дрёмина. Он недавно закончил 10 класс, скоро ему предстоит принять важное решение - кем он станет в этой жизни? Но у Женька есть одна особенность. Он жуткий фантазёр.
>
>Из-за этого в казалось бы самые рутинные моменты жизни он задумывается, проваливаясь в свою фантазию. Так самый непримечательный мальчик может стать программистом, поваром или итальянским сантехником.

### Цель игры:
Погрузиться в мир фантазий и прожить день из жизни Жени, проходя
мини-игры и взаимодействуя с интерактивными объектами.
 
### Тип проекта:
💻Видеоигра (Windows, Mac)

### Цель проекта:
Работая в команде, создать программный продукт, который заинтересует игроков от 12 лет своим сюжетом и увлекательными мини-играми.

### 🗒 Задачи:
- [x]  Написать сюжет;
- [x] Разработать дизайн персонажей;
- [x] Разработать дизайн игровых локаций и саунд-дизайн;
- [x] Реализовать игровые механики (головоломки, платформинг, ритм, диалоги);

### Структурная часть и соответствующие технологии:
- Язык программирования: С#
- Игровой движок: Unity
- Стиль графики: Пиксель-арт

### Управление

Общее управление
| Действие | Клавиши |
| :--- | :---: |
| Движение (все направления) | W A S D или ← ↑ → ↓ |
| Взаимодействие | R |

Платформинг
| Действие | Клавиши |
| :--- | :---: |
| Движение влево-вправо | A D или ← → |
| Прыжок | W, Space или ↑ |
| Рывок (Dash) | Left Shift |
| Переход на следующий уровень | Зажать R |
